# ProyectoMicroservicios

Esta carpeta contiene los microservicios principales del sistema:

- `Producto`: CRUD de productos, DTOs, validaciones, reglas de negocio y Swagger.
- `Inventario`: CRUD de inventario, validacion remota de productos con OpenFeign, consulta de stock bajo y Swagger.

La documentacion completa de ejecucion, rutas, pruebas y defensa esta en el README de la raiz del repositorio.
